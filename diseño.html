02 / THE BRIEF

THE PROJECT / MY ROLE

One developer. An entire online store.

SPACE JOB began as an independent fashion brand and became a full e-commerce platform. I designed and developed the experience myself over one year, connecting the storefront with payments, order management, inventory updates, customer emails and an internal administration panel.

01 / PROBLEM

Make shopping reliable.

The challenge was not just showing products; it was connecting navigation, a persistent cart, checkout, state-specific taxes and the order lifecycle into a working store.

02 / SOLUTION

Ship an integrated system.

I built the frontend with React and Next.js, used Node.js for backend development, Supabase for data, Stripe for payment processing, Resend for email, and Vercel for deployment.

08 / BUILD NOTES

10 QUESTIONS / MY IMPLEMENTATION

How I built SPACE JOB.

Ten answers about my development process, technical decisions, challenges and what I plan to improve next.

01 / OWNERSHIP

Who developed the platform, and how long did it take?

I built the entire store myself over one year. My work covered the responsive frontend, Node.js backend, data integration, persistent cart, checkout, customer emails, administration and deployment.

02 / FRONTEND

Which technologies did I choose for the frontend?

I used HTML, CSS, JavaScript, TypeScript, React and Next.js. I handled the mobile experience with CSS media queries so the storefront works across different screen sizes.

03 / BACKEND

How did I build the backend and connect the data?

I used Node.js for backend development and Supabase as the database service. These support the operational side of the store, including order-related data and inventory updates.

04 / CART

How does the shopping cart work?

I built the shopping cart myself and implemented persistence. Products stay in the cart when someone reloads the page instead of disappearing.

05 / STRIPE

How did I integrate payment processing?

I integrated Stripe through a custom API implementation and Stripe Checkout. One of the hardest parts was handling taxes across U.S. states while keeping the checkout and page navigation connected.

06 / ORDER LIFECYCLE

What happens after a successful payment?

The application generates an order, updates inventory, records the transaction and shows a confirmation to the customer. The post-purchase flow also includes an email notification.

07 / EMAIL

How does the email system work?

I integrated Resend to send messages for newsletter subscriptions, preorders and completed orders, covering communication before and after a purchase.

08 / ADMIN & DEPLOYMENT

How do I manage and deploy the store?

I have an admin panel for managing the store. I use Git and GitHub for version control, and Vercel hosts the live application.

09 / SECURITY & TESTING

How did I approach testing and security?

I tested the store before launch. I keep private keys in environment variables and use Stripe webhooks. I also recognize that security is an area I want to strengthen further.

10 / NEXT ITERATION

What would I improve in the next version?

My priorities are improving security and integrating the sign-in system I have already built. The login functionality is not yet connected to the live experience.

09 / SHIPPED PRODUCTSOLO BUILT / 1 YEAR

Built, deployed, and growing.

SPACE JOB is a live, full-stack store I built independently with Next.js, Node.js, Supabase, Stripe and Resend, deployed on Vercel. My next priorities are strengthening security and integrating the sign-in feature already under development.
